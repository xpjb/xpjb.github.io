Volatility-of-volatility walker

Turn probability is “volatility”; each step it does a random walk with exponential-sized moves (−ln U) and a random sign, scaled by VoV. Then you turn with probability = current volatility. Each walker has its own RNG stream (seed + id) so the count of walkers does not change other walkers’ paths. All start at the centre; distinct colours.
